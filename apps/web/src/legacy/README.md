# Legacy screens (JavaScript)

These are the original vanilla-JS screens, kept working while the rebuild happens.
They import the rules engine from the TypeScript package `@tp/engine`.

- `net.js`, `host.js`, `guest.js`, `qr.js` are replaced in Phase 2 (online tables) and Phase 5 (offline host app).
- `table.js`, `ui.js`, `fx.js`, `info.js`, `app.js` are replaced in Phase 6 (themes and table UI).

New code is TypeScript only. Nothing new goes in this folder.
